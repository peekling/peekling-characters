# Posh source artwork

Posh is rendered from deterministic geometric primitives at 1x, 2x, and 4x. The renderer creates the pearl-white orb, navy capsule eyes, cool lower-left shading, warm right rim, and transparent background directly at each density.

`posh-concept-v1.png` records the approved visual direction supplied for this character. The packaged atlases are original deterministic renders and do not copy pixels from the reference.
